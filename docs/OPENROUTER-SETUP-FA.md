# راه‌اندازی OpenRouter در هوش‌یار

## وضعیت پیاده‌سازی
- آداپتور OpenRouter به API چت هوش‌یار اضافه شده است.
- انتخاب‌گر موتور، گزینه OpenRouter را نشان می‌دهد و وضعیت فعال‌بودن آن را از سرور می‌خواند.
- در حالت «انتخاب خودکار»، اگر `OPENROUTER_API_KEY` تنظیم شده باشد، OpenRouter در اولویت قرار می‌گیرد.
- مدل پیش‌فرض `openrouter/free` است تا شروع آزمایش به مدل‌های رایگان محدود شود. مدل‌های رایگان ممکن است محدودیت ظرفیت و نرخ درخواست داشته باشند.
- کلید فقط در محیط سرور استفاده می‌شود و هرگز نباید به مرورگر یا مخزن Git ارسال شود.

## افزودن کلید در Cloudflare Pages
1. وارد Cloudflare Dashboard شوید و پروژه Pages با نام `houshyar-ai` را باز کنید.
2. به **Settings → Variables and Secrets** بروید.
3. در بخش **Environment Variables** یا **Secrets**، متغیر زیر را اضافه کنید:
   - Name: `OPENROUTER_API_KEY`
   - Value: کلید API ساخته‌شده در حساب OpenRouter
   - نوع: **Secret** (نه متغیر عمومی)
4. این تنظیم را برای **Production** فعال کنید. اگر می‌خواهید پیش‌نمایش‌ها هم از موتور استفاده کنند، آن را جداگانه در Preview اضافه کنید.
5. ذخیره کنید و یک بار پروژه را دوباره Deploy کنید تا Pages Functions متغیر جدید را دریافت کنند.

## ساخت کلید OpenRouter
1. به https://openrouter.ai/ بروید و وارد حساب خود شوید.
2. در بخش **Keys** یک API key بسازید.
3. برای کنترل هزینه، در صورت امکان محدودیت اعتبار/مصرف کلید را پایین تنظیم کنید.
4. کلید را فقط در Cloudflare Secret قرار دهید؛ آن را در چت، کد یا GitHub قرار ندهید.

## متغیرهای اختیاری
- `OPENROUTER_MODEL`: شناسه مدل؛ پیش‌فرض `openrouter/free`.
- `OPENROUTER_FALLBACK_MODELS`: فهرست مدل‌های جایگزین با کاما، حداکثر سه مدل.
- `HOUSHYAR_PUBLIC_URL`: آدرس عمومی هوش‌یار برای هدر معرفی برنامه؛ پیش‌فرض `https://houshyar-ai.pages.dev`.

برای استفاده از مدل پولی، ابتدا قیمت هر مدل و اعتبار حساب را بررسی کنید و سپس `OPENROUTER_MODEL` را تغییر دهید. در حالت پیش‌فرض هیچ مدل پولی به‌صورت خودکار انتخاب نمی‌شود.

## آزمایش پس از Deploy
1. آدرس `https://houshyar-ai.pages.dev/api/chat` را باز کنید؛ باید وضعیت OpenRouter در فهرست `providers` به صورت `available: true` دیده شود. این endpoint فقط وضعیت پیکربندی را نمایش می‌دهد و کلید را افشا نمی‌کند.
2. در هوش‌یار، تنظیمات پاسخ و مدل را باز کنید و **OpenRouter (چندمدلی)** را انتخاب کنید.
3. پیام آزمایشی «سلام، خودت را معرفی کن» را ارسال کنید.
4. در پاسخ API، مقدار `provider` باید `openrouter` باشد.

اگر پاسخ 401 دریافت شد، کلید را بررسی و در صورت افشا شدن فوراً باطل کنید. خطای 402 معمولاً به اعتبار ناکافی یا مدل پولی مربوط است؛ خطای 429 به محدودیت نرخ/ظرفیت اشاره می‌کند.
