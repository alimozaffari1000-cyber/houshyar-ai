# اتصال چندموتوره هوش‌یار (Cloudflare Pages)

## ارائه‌دهندگان مستقل

- **Groq**: مسیر سریع و سازگار با قالب OpenAI.
- **OpenAI**: اتصال مستقیم به API رسمی OpenAI؛ این سرویس با برنامه ChatGPT یکی نیست و کلید API و صورتحساب مستقل می‌خواهد.
- **Anthropic Claude**: اتصال مستقل Claude.

تمام کلیدها فقط باید در Secrets سمت سرور Cloudflare Pages ثبت شوند؛ هرگز در مرورگر، مخزن Git یا پیام گفتگو قرار نگیرند.

## متغیرهای محیطی

| نام | کاربرد |
|---|---|
| `GROQ_API_KEY` | کلید Groq |
| `OPENAI_API_KEY` | کلید رسمی OpenAI API |
| `CLAUDE_API_KEY` | کلید Anthropic |
| `AI_DEFAULT_PROVIDER` | انتخاب پیش‌فرض: `groq`، `openai` یا `anthropic` |
| `OPENAI_MODEL` | مدل پایه OpenAI؛ پیش‌فرض کد `gpt-6-astra` |
| `OPENAI_MODEL_FAST` / `OPENAI_MODEL_DEEP` / `OPENAI_MODEL_CREATIVE` | مدل‌های اختیاری هر حالت |
| `GROQ_MODEL` / `GROQ_MODEL_VISION` | مدل پایه Groq و مدل بینایی Groq |
| `CLAUDE_MODEL` | مدل پایه Claude |

مدل انتخابی باید در حساب API مربوطه قابل استفاده باشد. اگر کلید پیش‌فرض تنظیم نشده باشد، حالت خودکار از ارائه‌دهنده پیکربندی‌شده دیگر استفاده می‌کند. در حالت خودکار، اگر درخواست ارائه‌دهنده اصلی پیش از تولید اولین متن شکست بخورد، هوش‌یار یک‌بار به ارائه‌دهنده فعال بعدی منتقل می‌شود؛ در حالت انتخاب دستی، failover انجام نمی‌شود. اگر پاسخ جریانی بخشی از متن را فرستاده باشد یا درخواست به‌دلیل timeout لغو شده باشد، برای جلوگیری از پاسخ تکراری یا مصرف بی‌رویه، موتور عوض نمی‌شود. انتخاب دستی ارائه‌دهنده غیرفعال، خطای روشن می‌دهد.

## نقش هماهنگ‌کننده هوش‌یار

هسته گفتگو نقش هماهنگ‌کننده محصول را حفظ می‌کند: تحلیل درخواست، انتخاب عامل تخصصی، تعیین حالت پاسخ و در درخواست‌های پیچیده بازبینی و ترکیب پاسخ. این یک لایه نرم‌افزاری روی مدل انتخاب‌شده است؛ به معنی حضور مخفی یک مدل اختصاصی ChatGPT یا دسترسی به نشست ChatGPT نیست.

## مقایسه مدل‌ها

اگر حداقل دو ارائه‌دهنده فعال باشند، حالت مقایسه دو ارائه‌دهنده نخست پیکربندی‌شده را فراخوانی می‌کند. اگر فقط Groq فعال باشد، مقایسه دو مدل متفاوت Groq با `GROQ_MODEL_COMPARE_A` و `GROQ_MODEL_COMPARE_B` همچنان پشتیبانی می‌شود.

## آزمون و انتشار

پس از ثبت Secrets، در Pages Preview سلامت API، چت عادی، پاسخ جریانی، انتخاب دستی هر موتور و خطای کلید نامعتبر را بررسی کنید. این تغییرات هیچ تنظیم، کد یا استقرار Workers را انجام نمی‌دهند و Production را منتشر نمی‌کنند.
