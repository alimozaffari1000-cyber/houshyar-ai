# نقشه‌راه جامع محصول هوش‌یار

نسخه: ۱.۱  
وضعیت: برنامه اجرایی؛ موارد این سند تا زمان وجود کد، تست و استقرار تأییدشده، «انجام‌شده» محسوب نمی‌شوند.

## چشم‌انداز

ساخت یک دستیار هوش مصنوعی چندمنظوره، چندزبانه و قابل درآمدزایی که کاربران عادی و کسب‌وکارها بتوانند از آن برای گفتگو، پژوهش، تحلیل، تولید محتوا، ترجمه، برنامه‌ریزی و اجرای کارهای مجاز استفاده کنند.

## اصول غیرقابل مذاکره

- امنیت و حریم خصوصی از ابتدا در معماری لحاظ شوند.
- هیچ عامل هوش مصنوعی به‌صورت پیش‌فرض اختیار نامحدود نداشته باشد.
- کلیدها و اسرار فقط در محیط سرور نگهداری شوند.
- اقدام مالی، حذف داده، تغییر حساب و انتشار عمومی نیازمند کنترل انسانی باشد.
- نتیجه هر کار با وضعیت واقعی، گزارش و شواهد ارائه شود؛ کد نوشته‌شده با قابلیت عملیاتی اشتباه گرفته نشود.
- هزینه مدل و ابزار برای هر کاربر و هر درخواست قابل اندازه‌گیری و محدودسازی باشد.
- محصول ابتدا با حداقل قابلیت پایدار منتشر و سپس مرحله‌ای توسعه یابد.

## مدل درآمدی پیشنهادی

- پلن رایگان با سهمیه شفاف و محدود.
- پلن شخصی با اعتبار بیشتر و ابزارهای پیشرفته.
- پلن حرفه‌ای/کسب‌وکار با سقف مصرف و مدیریت تیم.
- API پولی برای توسعه‌دهندگان، پس از تکمیل احراز هویت و محدودیت نرخ.
- خدمات افزوده مثل پردازش فایل و گردش‌کارهای تخصصی، با قیمت‌گذاری شفاف.

هیچ پیش‌بینی درآمدی تضمین‌شده نیست؛ قیمت‌ها باید با هزینه واقعی مدل، کارمزد پرداخت، پشتیبانی، مالیات و بازار هدف محاسبه شوند.

## وضعیت فعلی قابل اثبات

- پروژه در GitHub و شاخه‌های توسعه فعال است.
- PRهای امنیت و حساب کاربری هنوز نیازمند ادغام وابستگی‌محور و CI موفق هستند.
- پرداخت رمزارزی فعلاً کاتالوگ/پایه API غیرفعال است، نه درگاه زنده.
- ایجنت‌ها در بخش مهمی طراحی معماری هستند و هنوز یک تیم مستقل عملیاتی کامل محسوب نمی‌شوند.
- اتصال Cloudflare، D1، سرویس ایمیل، provider و دامنه باید در حساب واقعی پیکربندی و آزمایش شود.
