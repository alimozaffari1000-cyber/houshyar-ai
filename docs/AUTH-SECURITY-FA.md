# تکمیل امنیت ورود و ثبت‌نام

## کنترل تلاش‌های ورود
- برای ورود و ثبت‌نام، محدودکننده پنجره‌ای ۱۵ دقیقه‌ای اضافه شده است.
- کلیدهای محدودکننده فقط هش SHA-256 ایمیل نرمال‌شده و IP معتبر Cloudflare هستند؛ ایمیل و IP خام در جدول محدودیت ذخیره نمی‌شوند.
- سقف پیش‌فرض ورود ۱۰ و ثبت‌نام ۵ تلاش در هر ۱۵ دقیقه است.
- متغیرهای AUTH_LOGIN_LIMIT و AUTH_REGISTER_LIMIT قابل تنظیم‌اند و سقف هرکدام در کد تا ۳۰ محدود شده است.
- در صورت نبود D1 یا خطای ذخیره‌سازی، endpoint با 503 متوقف می‌شود (fail-closed).

## محافظت CSRF
- endpointهای تغییردهنده حساب، Origin را اجباری می‌کنند و فقط Origin هم‌مبدأ را می‌پذیرند.
- درخواست فاقد Origin نیز رد می‌شود. کلاینت‌های غیرمرورگری که از این endpointها استفاده می‌کنند باید الگوی امن جداگانه داشته باشند.

## وضعیت حساب و سهمیه
- GET /api/auth/me وضعیت نشست و سهمیه روزانه را برمی‌گرداند.
- سهمیه بر اساس روز UTC محاسبه می‌شود.
- ثبت‌نام هنوز تأیید ایمیل ندارد و بازیابی رمز عبور پیاده‌سازی نشده است. بنابراین AUTH_ENABLED را در محیط عمومی فعال نکنید تا این قابلیت‌ها و فرایند بازیابی حساب کامل و بازبینی شوند.
- پاک‌سازی زمان‌بندی‌شده نشست‌ها و رکوردهای rate limit هنوز نیازمند job زمان‌بندی‌شده است.
