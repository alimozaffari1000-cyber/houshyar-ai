# راهنمای بازار محلی کشورها

## محدوده فعلی

بازارهای فعال در کد این شاخه: ایران (IR)، امارات (AE)، آلمان (DE) و ترکیه (TR). این فهرست تنظیمات نرم‌افزاری است، نه تأیید آمادگی حقوقی یا پرداخت در آن کشورها.

## API

- `GET /api/market/listings?country=AE`: فقط آگهی‌های `published` همان کشور و فروشگاه‌های `active` را برمی‌گرداند.
- `GET /api/market/stores?country=DE`: فقط فروشگاه‌های فعال همان کشور را برمی‌گرداند.
- `GET /api/market/my-stores`: فروشگاه‌های متعلق به کاربر واردشده را همراه وضعیت moderation برمی‌گرداند.
- `POST /api/market/stores`: ساخت فروشگاه؛ نیازمند نشست معتبر و Origin هم‌دامنه است. وضعیت اولیه `pending` است.
- `POST /api/market/listings`: ثبت آگهی زیر فروشگاه متعلق به همان کاربر و همان کشور؛ وضعیت اولیه `pending` است.
- `POST /api/market/moderate`: فقط مدیر دارای نقش `admin` می‌تواند فروشگاه یا آگهی را تأیید یا رد کند. تأیید آگهی فقط پس از فعال‌شدن فروشگاه ممکن است.

## قرارداد ثبت فروشگاه

```json
{
  "country": "AE",
  "name": "Example Store",
  "slug": "example-store",
  "description": "Store description",
  "city": "Dubai"
}
```

## قرارداد ثبت آگهی

```json
{
  "country": "AE",
  "storeId": "STORE_ID",
  "category": "fashion",
  "title": "Product title",
  "description": "Product details",
  "city": "Dubai",
  "price": 125,
  "listingType": "offer"
}
```

قیمت در واحد اصلی ارز همان کشور ثبت می‌شود؛ تبدیل ارز انجام نمی‌شود. در ایران فعلاً کد پولی IRR است و نحوه نمایش تومان/ریال باید قبل از دریافت سفارش نهایی شود.

## گیت‌های راه‌اندازی

1. در Cloudflare Pages binding با نام دقیق `DB` به D1 متصل شود.
2. قبل از migration جدید، وضعیت و پشتیبان migrationهای قبلی بررسی شود؛ سپس `0010_country_marketplace.sql` اعمال شود.
3. نقش مدیر از طریق مسیر مدیریتی امن و خارج از رابط عمومی به حساب‌های مورد اعتماد اختصاص یابد؛ هیچ endpoint عمومی برای ارتقای نقش وجود ندارد.
4. پنل مدیریت moderation، پنل فروشنده، آپلود امن تصویر، پیام‌رسانی، سفارش، مرجوعی، پرداخت، ارسال و پشتیبانی هنوز لازم‌اند.
5. قبل از فعال‌سازی هر کشور، قوانین فروش/حریم خصوصی/مالیات، کالاهای ممنوع، احراز هویت فروشنده، روش پرداخت و تسویه محلی جداگانه بررسی شوند.
6. هیچ داده‌ای از دیوار یا شیپور scrape یا کپی نمی‌شود؛ بازار با آگهی‌هایی که کاربران در هوش‌یار ثبت می‌کنند رشد می‌کند.
