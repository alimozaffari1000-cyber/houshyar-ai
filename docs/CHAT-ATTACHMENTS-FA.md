# پیوست امن در گفتگوی هوش‌یار

## محدوده نسخه فعلی

- حداکثر دو تصویر در هر پیام؛ هر تصویر حداکثر ۲ مگابایت و مجموع تصاویر حداکثر ۴ مگابایت.
- قالب‌های تصویر مجاز: JPEG، PNG، WebP و GIF.
- فایل‌های متنی TXT، MD و CSV تا ۴ کیلوبایت در مرورگر خوانده و به متن پیام اضافه می‌شوند.
- فایل‌های اجرایی، آرشیوها، اسناد PDF و قالب‌های ناشناخته در این نسخه پشتیبانی نمی‌شوند.
- تصویرها در این مسیر روی D1 یا R2 ذخیره نمی‌شوند؛ فقط برای همان درخواست به ارائه‌دهنده مدل ارسال می‌شوند.

## کنترل‌های امنیتی

- محدودیت اندازه درخواست در API اعمال می‌شود؛ بررسی سمت مرورگر به‌تنهایی مبنای اعتماد نیست.
- تعداد، MIME type، کدگذاری Base64، اندازه واقعی و امضای باینری تصویر در سرور بررسی می‌شود.
- MIME اعلام‌شده باید با امضای واقعی فایل مطابقت داشته باشد.
- محتوای پیوست در تاریخچه محلی گفتگو ذخیره نمی‌شود؛ متن فایل متنی ممکن است در متن همان پیام گفتگو قرار بگیرد.
- کاربران نباید تصاویر یا اسناد حاوی اطلاعات محرمانه را بدون توجه به سیاست داده ارائه‌دهنده مدل ارسال کنند.

## تنظیم مدل بینایی

- اگر ارائه‌دهنده روی حالت خودکار باشد و کلید Claude تنظیم شده باشد، درخواست دارای تصویر به Anthropic هدایت می‌شود.
- برای انتخاب دستی Groq، متغیر محرمانه Pages با نام `GROQ_MODEL_VISION` باید به شناسه یک مدل بینایی فعال و سازگار با API چت Groq تنظیم شود.
- این قابلیت تا زمان تنظیم کلیدها و آزمایش درخواست واقعی در Pages Preview، تأیید عملیاتی محسوب نمی‌شود.

## آزمون

تست‌های API امضای فایل، رد MIME جعلی، محدودیت اندازه و مسیریابی تصویر به Claude را پوشش می‌دهند.
