# پایه احراز هویت هوش‌یار

این مرحله مسیرهای ثبت‌نام، ورود، خروج و مشاهده نشست جاری را اضافه می‌کند. همه مسیرها فقط پس از آماده‌شدن D1 و تنظیم AUTH_ENABLED=true فعال می‌شوند.

## تنظیمات
- D1 binding با نام DB
- اجرای migration شماره 0001_identity_usage_security.sql
- متغیر AUTH_ENABLED=true فقط پس از اجرای migration و بررسی محیط Preview
- رمز عبور حداقل ۱۲ و حداکثر ۱۲۸ نویسه؛ ذخیره‌سازی با PBKDF2-HMAC-SHA256 و salt تصادفی
- توکن نشست تصادفی ۲۵۶ بیتی؛ فقط هش SHA-256 توکن در D1 ذخیره می‌شود
- کوکی نشست HttpOnly، Secure، SameSite=Lax و ۳۰ روزه است

## مسیرها
- POST /api/auth/register
- POST /api/auth/login
- POST /api/auth/logout
- GET /api/auth/me

## محدودیت‌های پیش از انتشار عمومی
- تأیید ایمیل و بازیابی رمز عبور هنوز پیاده‌سازی نشده است؛ ثبت‌نام عمومی را تا افزودن تأیید ایمیل باز نکنید.
- برای مسیرهای ثبت‌نام و ورود باید محدودیت نرخ مستقل و محافظت در برابر credential stuffing تنظیم شود.
- محدودسازی CORS/Origin و CSRF باید همراه با دامنه نهایی و جریان frontend بازبینی شود.
- پاک‌سازی نشست‌های منقضی و مدیریت نشست‌های هم‌زمان هنوز نیازمند job زمان‌بندی‌شده است.
- هیچ رمز یا توکن محرمانه‌ای در مخزن قرار ندهید.
