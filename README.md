# Houshyar AI

هوش‌یار یک دستیار هوش مصنوعی چندمنظوره، فارسی‌محور و راست‌به‌چپ است که با Vite و Cloudflare Pages Functions ساخته می‌شود.

## وضعیت واقعی پروژه

- توسعه قابلیت‌های جدید در شاخه `feature/local-store-discovery-ui` و PR شماره ۸۲ انجام می‌شود؛ این شاخه هنوز با `main` ادغام نشده است.
- اجرای قابلیت‌های حساب کاربری و بازارگاه در محیط واقعی به اتصال و آزمون D1، R2 خصوصی، secrets و تنظیمات Pages وابسته است.
- رابط چندزبانه پایه برای ۱۲ زبان وجود دارد؛ این به معنی ترجمه کامل همه زبان‌های جهان نیست.
- هسته چت از Groq، OpenAI و Anthropic پشتیبانی می‌کند؛ استفاده از هرکدام به Secret معتبر و مدل فعال در حساب همان ارائه‌دهنده نیاز دارد.
- پاسخ جریانی برای درخواست‌های تک‌عاملی پشتیبانی می‌شود؛ درخواست‌های همکاری چندعاملی و مقایسه مدل‌ها فعلاً مسیر پاسخ کامل را دارند.
- فایل‌های تصویری و متنی کوچک می‌توانند برای همان درخواست چت ارسال شوند؛ تصاویر در تاریخچه محلی ذخیره نمی‌شوند و برای درخواست جاری به ارائه‌دهنده سازگار فرستاده می‌شوند.
- عامل‌های QA، امنیت و کیفیت در قالب workflowهای GitHub اجرا می‌شوند؛ تیم خودمختار با اختیار تغییر و انتشار Production وجود ندارد.
- پرداخت بانکی و رمزارزی، سبد خرید چندمحصولی، تحویل خودکار، و تولید واقعی تصویر برای پرو مجازی/چیدمان خانه هنوز عملیاتی نیستند.

## امکانات موجود در کد

- رابط واکنش‌گرای چت فارسی RTL و پشتیبانی پایه ۱۲ زبان
- انتخاب موتور Groq، OpenAI و Claude، حالت خودکار و failover محدود پیش از شروع پاسخ
- پاسخ جریانی، توقف درخواست و پشتیبانی کنترل‌شده از تصویر و فایل متنی
- هماهنگ‌کننده عامل‌های تخصصی و حالت‌های پاسخ سریع، متعادل، عمیق و خلاق
- فضای کاری و استودیو طراحی
- پایه API حساب کاربری، نشست امن، سهمیه و محدودیت نرخ با قابلیت فعال‌سازی کنترل‌شده
- بازارگاه آزمایشی: جست‌وجوی فروشگاه و محصول، فیلتر ارسال/تحویل حضوری، پروفایل فروشنده، تصاویر خصوصی محصول و درخواست سفارش
- تاریخچه سفارش خریدار و کسر اتمیک موجودی هنگام پذیرش سفارش توسط فروشنده
- پیش‌نمایش محلی پرو مجازی و چیدمان خانه؛ بدون تولید خروجی هوش مصنوعی در نسخه فعلی
- تست‌های Node.js، اسکن امنیتی، بررسی کیفیت و کنترل ساخت

## توسعه محلی

## استقرار Cloudflare Pages

این پروژه برای Cloudflare Pages است، نه Workers Builds:
- Build command: `npm run build`
- Output directory: `dist`
- Root directory: `/`
- APIها در پوشه `functions/` به‌صورت Pages Functions اجرا می‌شوند.
- Secretهای ارائه‌دهنده AI فقط در تنظیمات Pages ثبت شوند؛ هیچ کلیدی را در Git یا کد مرورگر قرار ندهید.

راهنمای راه‌اندازی و امنیت:
- `docs/AI-PROVIDERS-FA.md`
- `docs/CHAT-ATTACHMENTS-FA.md`
- `docs/PAGES-D1-SETUP-FA.md`
- `docs/PAGES-STAGING-CHECKLIST-FA.md`
- `docs/MARKETPLACE-ORDERS-FA.md`
- `docs/PRODUCT-MEDIA-SETUP-FA.md`

## گیت‌های امنیت و انتشار

- D1 binding باید دقیقاً `DB` و برای تصاویر فروشگاه R2 خصوصی با binding برابر `MEDIA_BUCKET` باشد.
- Migrationهای `0001` تا `0008` فقط پس از بررسی تاریخچه و backup روی Staging اجرا شوند؛ هیچ migrationی در این روند روی Production اجرا نشود.
- دسترسی عمومی `r2.dev` برای تصاویر خصوصی فروشندگان خاموش بماند.
- احراز هویت، سهمیه و محدودسازی نرخ فقط پس از اتصال و آزمون تمام وابستگی‌ها فعال شوند.
- پیش از انتشار، تست‌های خودکار، سه workflow امنیت/کیفیت/نگهبان و تمام آزمون‌های دستی Pages Preview با D1 و R2 آزمایشی باید موفق باشند.
- پیش‌نویس حریم خصوصی و شرایط استفاده باید پیش از عرضه عمومی بازبینی حقوقی شوند.
- هیچ Secret، کلید API یا رمز عبور نباید در مخزن، خروجی مرورگر یا گفتگو قرار بگیرد.
- هیچ تغییر یا استقراری در Cloudflare Workers انجام ندهید؛ این پروژه از مسیر Cloudflare Pages منتشر می‌شود.
- ادغام PR و انتشار Production فقط پس از تأیید صریح مالک پروژه مجاز است.
