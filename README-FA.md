# هوش‌یار AI — نسخه ۰.۶

دستیار هوشمند چندمنظوره فارسی، با رابط راست‌چین و ساختار آماده توسعه.

## اجرا
- Node.js نسخه ۲۰ یا بالاتر
- `npm install`
- `npm run dev`

## آزمون و ساخت
- `npm run qa`
- `npm run build`

## اتصال هوش مصنوعی
رابط کاربری فقط به یک endpoint امن سرور متصل می‌شود. کلید Groq یا هر ارائه‌دهنده مدل را هرگز در متغیرهای `VITE_*` یا کد مرورگر قرار ندهید. ابتدا یک API سمت سرور/Worker بسازید و کلید را به‌صورت Secret در محیط اجرا تنظیم کنید؛ سپس `VITE_AI_ENDPOINT` را به مسیر عمومی همان API تنظیم کنید.

## کنترل کیفیت
GitHub Actions با هر push و pull request و نیز روزانه ساعت 05:00 UTC، تست‌ها و build را اجرا می‌کند.


## عامل نگهبان و تعمیر محدود خودکار

- `npm run agent:repair`: فقط اصلاحات امن و از پیش‌تعریف‌شده در `.gitignore` و تنظیم خروجی Cloudflare Pages را انجام می‌دهد.
- `npm run agent:check`: ساختار پروژه و خطرهای ابتدایی افشای کلید را بررسی می‌کند.
- GitHub Actions این مراحل را پس از push و هر روز اجرا می‌کند و اصلاحات مجاز را به شاخه اصلی commit می‌کند.
- تغییر منطق برنامه، حذف فایل‌ها، دسترسی به حساب Cloudflare و خواندن یا تغییر Secretها جزو اختیارات خودکار نیستند.
