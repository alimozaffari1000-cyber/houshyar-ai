# هوش‌یار AI — نسخه ۰.۶

دستیار هوشمند چندمنظوره با رابط فارسی، راست‌چین و سازگار با موبایل. مخزن شامل رابط کاربری، API سمت سرور، پایه حساب کاربری و امنیت، ترجمه پایه چندزبانه و آزمون‌های خودکار است.

## وضعیت فعلی

- PR شماره ۳۸ در تاریخ ۲۰ آبان ۱۴۰۵ به شاخه اصلی ادغام شده است.
- پایه D1، ثبت‌نام و ورود، نشست‌ها، جداسازی داده حساب‌ها، محدودیت نرخ، سهمیه روزانه، تأیید ایمیل و بازیابی رمز در کد شاخه اصلی قرار دارند.
- این قابلیت‌ها هنوز در محیط واقعی فعال نیستند؛ راه‌اندازی D1 و migrationها، سرویس ایمیل، secrets و آزمون end-to-end در Cloudflare لازم است.
- رابط پایه ۱۲ زبان را پوشش می‌دهد؛ ترجمه کامل تمام زبان‌های جهان هنوز انجام نشده است.
- عامل‌های آزمون، امنیت و کیفیت در GitHub Actions بررسی‌های خودکار اجرا می‌کنند؛ این به معنی وجود تیم خودمختار با دسترسی نامحدود نیست.
- پرداخت رمزارزی واقعی هنوز فعال نیست.

## امکانات پیاده‌سازی‌شده در مخزن

- رابط گفت‌وگوی فارسی و واکنش‌گرا با جهت RTL
- اتصال سمت سرور به Groq از مسیر /api/chat
- کنترل اندازه درخواست، طول پیام و تاریخچه و timeout
- پایه API حساب کاربری، نشست امن و جداسازی حساب‌ها
- محدودیت نرخ و سهمیه روزانه با تنظیمات opt-in
- پایه تأیید ایمیل و بازیابی رمز عبور
- پشتیبانی رابط از ۱۲ زبان پایه
- آزمون‌های Node.js، اسکن امنیتی و بررسی کیفیت/حجم build

## اجرا

نیازمند Node.js نسخه ۲۰ یا بالاتر:

```bash
npm install
npm run dev
```

## آزمون و ساخت

```bash
npm run qa
npm run agent:check
npm run security:scan
npm run build
npm run quality:check
```

## اتصال هوش مصنوعی

کلید Groq را فقط در Secret سمت سرور Cloudflare با نام GROQ_API_KEY قرار بده. کلید را در کد مرورگر، متغیرهای VITE_*، مخزن Git یا گفتگو وارد نکن.

## استقرار

پروژه باید به‌صورت Cloudflare Pages متصل شود:
- Build command: npm run build
- Output directory: dist
- Root directory: /

برای حساب کاربری، D1 با binding دقیق DB و migrationهای 0001 تا 0003 لازم است. تأیید ایمیل به دامنه HTTPS، سرویس ایمیل سازگار و secrets نیاز دارد. راهنمای مرحله‌به‌مرحله در CLOUDFLARE-SETUP-FA.md است.

## وضعیت آمادگی انتشار

هوش‌یار هنوز برای عرضه عمومی تأیید نشده است. تا تکمیل پیکربندی Cloudflare Pages، D1، migrationها، secrets، سرویس ایمیل و تست end-to-end، قابلیت‌های حساب و سهمیه در production نباید فعال شوند. پرداخت واقعی، پنل مدیریت کامل، تاریخچه پایدار گفتگو، پایش عملیاتی، پشتیبان‌گیری، بازبینی حقوقی حریم خصوصی و تست نفوذ مستقل نیز نیازمند تکمیل‌اند.

هیچ کلید محرمانه‌ای را در GitHub، کد فرانت‌اند یا گفتگو قرار ندهید.
