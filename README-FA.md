# هوش‌یار AI — نسخه ۰.۶

دستیار هوشمند چندمنظوره با رابط فارسی، راست‌چین و سازگار با موبایل. این مخزن شامل کد رابط کاربری، API سمت سرور و آزمون‌های خودکار است.

## امکانات فعلی

- رابط گفت‌وگوی فارسی و واکنش‌گرا
- اتصال سمت سرور به Groq از مسیر `/api/chat`
- محدودسازی تاریخچه و طول پیام‌ها
- سقف ۳۲ کیلوبایتی برای بدنه درخواست API
- مهلت ۲۰ ثانیه‌ای برای پاسخ سرویس بالادستی
- آزمون‌های Node.js، بررسی امنیت پایه و کنترل کیفیت ساخت

## اجرا

نیازمند Node.js نسخه ۲۰ یا بالاتر:

```bash
npm install
npm run dev
```

## آزمون و ساخت

```bash
npm run qa
npm run agent:check
npm run security:scan
npm run build
npm run quality:check
```

## اتصال هوش مصنوعی

کلید Groq را فقط در Secret سمت سرور Cloudflare با نام `GROQ_API_KEY` قرار بده. کلید را در کد مرورگر، متغیرهای `VITE_*`، مخزن Git یا گفتگو وارد نکن.

راهنمای راه‌اندازی: [CLOUDFLARE-SETUP-FA.md](CLOUDFLARE-SETUP-FA.md)

## وضعیت آمادگی انتشار

این پروژه هنوز نمونه اولیه است و برای استفاده عمومی پرترافیک آماده نیست. مسیر چت فعلاً احراز هویت کاربر و سهمیه/محدودیت نرخ مستقل برای هر کاربر ندارد. پیش از عمومی‌کردن سرویس باید کنترل سوءاستفاده سمت سرور، محدودیت نرخ، کنترل هزینه، پایش خطا و سیاست حریم خصوصی اضافه و آزمایش شوند.

حساب کاربری، پرداخت، ذخیره دائمی تاریخچه و جداسازی داده کاربران هنوز پیاده‌سازی نشده‌اند. آزمون‌های خودکار نیز جایگزین آزمون نفوذ یا بررسی محیط عملیاتی نیستند.

## عامل‌های کنترل کیفیت

- `npm run agent:check`: بررسی ساختار و موارد پایه امنیتی
- `npm run security:scan`: اسکن ایستای امنیتی
- `npm run quality:check`: بررسی کیفیت، دسترس‌پذیری و بودجه حجم خروجی
- GitHub Actions آزمون‌ها و ساخت پروژه را اجرا می‌کند؛ وضعیت هر اجرا در تب Actions مخزن قابل مشاهده است.
