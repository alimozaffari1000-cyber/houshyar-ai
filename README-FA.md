# هوش‌یار AI — نسخه ۰.۶

هوش‌یار یک دستیار هوش مصنوعی چندمنظوره، فارسی‌محور و راست‌چین است. مخزن شامل وب‌اپ واکنش‌گرا، APIهای سمت سرور Cloudflare Pages، چت چندارائه‌دهنده‌ای، پایه بازارگاه محلی و آزمون‌های خودکار است.

## وضعیت واقعی شاخه اصلی

- رابط کاربری با Vite ساخته و برای Cloudflare Pages و Pages Functions آماده شده است.
- چت سمت سرور از Groq، Claude / Anthropic و Google Gemini پشتیبانی می‌کند؛ فعال بودن هر ارائه‌دهنده به Secret معتبر سمت سرور وابسته است.
- جست‌وجوی Google Search برای Gemini اختیاری است و فقط در صورت فعال‌کردن کاربر و دریافت داده grounding از Google، منابع نمایش داده می‌شوند.
- رابط پایه ۱۲ زبان دارد؛ این به معنی ترجمه کامل همه زبان‌های جهان نیست. فارسی و عربی راست‌چین و زبان‌های دیگر با جهت متناسب نمایش داده می‌شوند.
- بازارگاه شامل کشف فروشگاه و محصول، جست‌وجوی اختیاری نزدیک من، پنل پایه فروشنده، ثبت محصول و درخواست سفارش خریدار است.
- سفارش‌های بازارگاه در این مرحله فقط درخواست بین خریدار و فروشنده‌اند؛ پرداخت آنلاین، تسویه، دریافت آدرس منزل و ارسال واقعی فعال نیست. موجودی هنگام پذیرش فروشنده کنترل و به‌روزرسانی می‌شود.
- پایه D1، نشست و احراز هویت، محدودیت نرخ، سهمیه و بازیابی حساب در کد وجود دارد؛ این قابلیت‌ها تا پیکربندی و آزمون کامل محیط Cloudflare نباید در Production فعال فرض شوند.
- فایل‌های migration شماره 0001 تا 0007 در مخزن وجود دارند. وجود فایل در Git به معنی اجرای آن روی پایگاه D1 نیست؛ پیش از هر اجرا باید تاریخچه واقعی پایگاه و ترتیب migrationها بررسی شود.
- پرداخت رمزارزی عملیاتی نیست. پایه طراحی پرو مجازی و برخی قابلیت‌های تصویری نیز به معنی آماده‌بودن سرویس واقعی نیستند.
- آزمون‌گر، نگهبان امنیت و عامل کیفیت در قالب GitHub Actions اجرا می‌شوند؛ تیم خودمختار همیشه‌فعال با اختیار تغییر یا انتشار Production وجود ندارد.

## امکانات موجود در کد

- رابط چت فارسی RTL و واکنش‌گرا
- مسیریابی خودکار یا انتخاب دستی Groq، Claude و Gemini
- جست‌وجوی وب اختیاری Gemini همراه با نمایش منابع دریافت‌شده
- کنترل طول پیام و تاریخچه، اندازه درخواست و timeout
- پایه حساب کاربری و نشست امن با جداسازی داده کاربران
- محدودیت نرخ و سهمیه با فعال‌سازی کنترل‌شده
- کشف فروشگاه‌ها و محصولات ثبت‌شده در هوش‌یار
- فیلتر روش دریافت، جست‌وجوی شهر و مرتب‌سازی اختیاری بر اساس موقعیت
- پنل پایه فروشنده و گردش درخواست سفارش خریدار/فروشنده
- تست‌های Node.js، اسکن امنیتی، ممیزی کیفیت و بودجه حجم Build

## استقرار Cloudflare Pages

این مخزن برای **Cloudflare Pages** است، نه Workers Builds:

- Root directory: `/`
- Build command: `npm run build`
- Output directory: `dist`
- APIهای پوشه `functions/` به‌صورت Pages Functions اجرا می‌شوند.

کلیدهای ارائه‌دهندگان فقط باید به‌صورت Secret سمت سرور تنظیم شوند؛ مانند `GROQ_API_KEY`، `CLAUDE_API_KEY` و `GEMINI_API_KEY`. هیچ کلیدی را در Git، کد مرورگر، متغیرهای `VITE_*` یا گفتگو قرار ندهید.

برای حساب کاربری، binding پایگاه D1 باید دقیقاً `DB` باشد. قبل از اجرای migration روی Production، از پایگاه نسخه پشتیبان تهیه کنید و تاریخچه واقعی migrationها را با فایل‌های مخزن تطبیق دهید. راهنمای فارسی در `CLOUDFLARE-SETUP-FA.md` و مستندات پوشه `docs/` قرار دارد.

## گیت‌های لازم پیش از عرضه عمومی

تا وقتی موارد زیر در محیط آزمایشی و سپس با تأیید انسانی در Production بررسی نشده‌اند، هوش‌یار را آماده عرضه عمومی فرض نکنید:

1. دسترسی واقعی دامنه Pages و موفقیت Deployment شاخه `main`
2. اتصال D1 و اجرای کنترل‌شده migrationهای تأییدشده
3. تنظیم امن Secrets و آزمون end-to-end هر ارائه‌دهنده هوش مصنوعی
4. تنظیم R2 خصوصی و آزمون چرخه بارگذاری، دسترسی و پاک‌سازی تصویر
5. راه‌اندازی سرویس ایمیل و آزمون ثبت‌نام، ورود و بازیابی حساب
6. محدودسازی نرخ، سهمیه، پایش خطا و هزینه ارائه‌دهندگان
7. بازبینی حقوقی سیاست حریم خصوصی و آزمون امنیت مستقل
8. بررسی کامل جریان سفارش پیش از هرگونه فعال‌سازی پرداخت یا تسویه

موفقیت GitHub Actions یا Cloudflare Preview به‌تنهایی اثبات نمی‌کند که دامنه Production، پایگاه داده یا همه سرویس‌های بیرونی عملیاتی هستند.
